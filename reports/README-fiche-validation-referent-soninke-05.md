# Fiche du référent linguistique — lot 05

Cette fiche reprend les segments source du lot 05. Elle est destinée à la validation par le référent Soninké–français.

Pour chaque lemme :
- renseigner `validation_referent` (par exemple : confirmé, à corriger, à vérifier);
- renseigner `lemme_corrige` si la graphie doit être ajustée;
- renseigner `traduction_fr_confirmee` avec une traduction confirmée;
- consigner les variantes, sens et exemples à conserver;
- utiliser les commentaires pour signaler l'incertitude ou les divergences.

**Important :** aucune entrée n'est considérée validée du seul fait de la préparation de cette fiche. Ne pas importer les candidats tant que leur contenu linguistique n'est pas confirmé.
