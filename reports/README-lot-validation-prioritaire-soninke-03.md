# Lot 3 de validation linguistique — Soninké–français

Ce lot poursuit l'extraction du fichier `Dictionnaire soninké.docx` et l'enrichissement progressif du lexique.

- **50 lemmes candidats distincts**.
- **53 segments source** conservés pour préserver les sens multiples et variantes.
- Comparaison faite avec la base courante (**305 entrées**) et les lots déjà préparés.
- Aucun lemme du lot ne correspond à un lemme canonique déjà présent dans la base.
- Les candidats ayant un renvoi explicite vers une entrée principale dans l'un de leurs segments ont été exclus de ce lot.
- **Aucune entrée de ce lot n'est importée** : ce lot est préparé pour validation linguistique. La confirmation antérieure des lots 1 et 2 ne vaut pas validation de ces nouveaux candidats.
- L'ordre suit les paragraphes source restants; il ne constitue pas un jugement de certitude linguistique.
- Les suffixes numériques ont été regroupés sous un lemme canonique pour conserver les sens ensemble. Si des homonymes doivent être séparés, le référent peut le préciser dans la fiche.
- Les gloses automatiques peuvent être incomplètes ou erronées; consulter le texte source complet avant de confirmer.
