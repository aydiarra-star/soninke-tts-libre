# Lot prioritaire de validation lexicale — Soninké–français

Ce lot contenait **50 étiquettes de lemmes candidates** réparties sur 71 segments source. Le référent linguistique a confirmé le lot le 21 octobre 2026; les entrées ont été intégrées à la base après regroupement des suffixes numériques qui identifiaient les homonymes dans la source.

- Source : `Dictionnaire soninké.docx`, via l'extraction lexicale.
- Base mise à jour : `data/lexique-soninke-fr-base.csv`.
- **Résultat de l'import : 42 lemmes canoniques ajoutés**, car les formes suffixées par un chiffre (ex. `baana1`, `baana2`) ont été regroupées sous un seul lemme `baana`.
- Les traductions et définitions confirmées ont été regroupées dans le champ français. Les formes variantes et les références aux segments source sont indiquées dans le champ source de la base.
- Les 71 segments complets, avec exemples, variantes et provenance, restent conservés dans les colonnes `texte_source_complet` de la fiche de validation.
- Les catégories mixtes sont indiquées lorsque le même lemme possède des emplois nominaux et verbaux.
- Contrôle anti-doublon effectué après import : 255 entrées, 255 lemmes distincts.

## Résumé

- Lignes source conservées dans le lot : 71
- Étiquettes de lemmes candidates initiales : 50
- Lemm es canoniques ajoutés à la base : 42
- Lemm es déjà présents dans la base avant import : 0
- Lemm es dupliqués après import : 0

L'ordre initial de priorité était une aide de tri, pas une mesure de certitude linguistique. La validation globale a ensuite été explicitement confirmée par le référent.
