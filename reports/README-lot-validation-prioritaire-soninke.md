# Lot prioritaire de validation lexicale — Soninké–français

Ce lot contient **50 lemmes candidats distincts**, choisis parmi les entrées du document source absentes du lexique de projet au moment de la comparaison. Toutes les lignes source associées aux 50 lemmes retenus sont conservées afin de ne pas perdre les sens multiples.

- Source : `Dictionnaire soninké.docx`, via l'extraction `lexique_soninke_extrait.csv`.
- Règle anti-doublon : comparaison exacte après normalisation Unicode NFC, suppression des espaces superflus et comparaison sans distinction de casse.
- **Aucune entrée n'a été importée dans la base principale.** Ce lot sert à la validation linguistique.
- Les gloses ont été extraites automatiquement et peuvent être tronquées ou mal alignées; la colonne `texte_source_complet` et le numéro de paragraphe sont à privilégier lors de la vérification.
- Si un lemme comporte plusieurs sens, conserver un seul lemme et rattacher les sens/variantes validés à cette entrée.
- Les formes de renvoi (« See main entry ») ne sont pas promues automatiquement au rang de nouveaux lemmes.

## Résumé

- Lignes source examinées : 787
- Lemmes distincts dans la source : 632
- Lemmes distincts déjà présents dans le projet : 6
- Lemmes retenus dans ce lot : 50
- Lignes source conservées dans ce lot : 71

Ordre de priorité établi par la présence d’une glose et d’une définition descriptive exploitable; cet ordre est une aide de tri, pas une validation linguistique.
