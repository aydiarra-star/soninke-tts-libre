# Fiche du référent linguistique — lot 06

Cette fiche reprend les segments source du lot 06. Elle est destinée à la validation par le référent Soninké–français.

Pour chaque lemme :
- renseigner `validation_referent` (par exemple : confirmé, à corriger, à vérifier);
- renseigner `lemme_corrige` si la graphie doit être ajustée;
- renseigner `traduction_fr_confirmee` avec une traduction confirmée;
- consigner les variantes, sens et exemples à conserver;
- utiliser les commentaires pour signaler l'incertitude ou les divergences.

**Important :** la préparation de cette fiche ne constitue pas une validation. Ne pas importer les candidats tant que leur contenu linguistique n'est pas confirmé.
