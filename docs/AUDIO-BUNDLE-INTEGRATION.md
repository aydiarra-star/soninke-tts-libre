# Intégration du lot audio du lexique

Les WAV disponibles sont servis sous audio/ et référencés dans data/audio-manifest.json. La page lexique affiche un lecteur HTML5 pour chaque entrée avec WAV. Une entrée sans fichier reste visible avec un message explicite.

## Contrôles du lot

- Entrées du manifeste: 577
- WAV distincts valides: 576
- Identifiants sans WAV: snk-00308
- Le doublon exact Copie de snk-00001.wav est ignoré.
- Aucun audio n'est fabriqué pour combler une absence.

La validation linguistique reste distincte de la disponibilité technique.
